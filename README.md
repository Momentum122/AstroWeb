# AstroWeb
AstroWeb is a lightweight , futuristic , web-based new tab page built with HTML,CSS, and Javascript. It features a translucent,space-themed aesthetic , a centered web search bar , a live clock and date widget , and a dynamic card fethcing the live NASA astronomy picture of the day (APOD)
# Features 
1. centered web search bar :- Instantly search the web using google.
2. Live NASA APOD integretion :- Dynamically fetches real-time astronomy photos, titles, and explanations straight from NASA's official API
3. Cosmic Glassmorphism Ui :- A modern dark mode interface utilizing backdrop blurring , glowing accentns and sleek hihg tech styling.
4. Live CLock and Date widget :- Displays real-time local time with seconds and 12 hour format , along with full date , day , month and year .
5. Fallback system :- built-in error handling to ensure the app always displays a breathtaking deep-space wallpaper and card details even if NASA's servers experience high traffic.
# File Structue
